# Совместимость с Go

Русский · [English](COMPATIBILITY.md) · [На главную](../Readme.ru.md)

MinLZ C реализует базовый формат блоков и потоков и поисковые расширения
v1.2.0. Формат описан в [SPEC.md](../SPEC.md) и
[SPEC_SEARCH.md](../SPEC_SEARCH.md). Эталоном поведения служит Go.

## Реализованные возможности

- Все уровни блоков и потоков: superfast, raw, fastest, balanced, smallest.
- Идентификаторы потоков, маскированный CRC32C, конечный размер, заполнение,
  пропускаемые чанки, объединённые потоки, загрузка, построение и поиск по индексу.
- Объекты чтения и записи, файловые обёртки, функции обратного вызова,
  ReadSeeker и ReadAt.
- Чанки поиска `0x44`–`0x47`, таблицы без префикса, с байтовым, масочным
  и длинным префиксом, поиск одного префикса в хвосте последнего блока,
  совпадения через короткие блоки Flush.
- Raw, RLE, разреженные, индивидуальные и общие таблицы Huff0/FSE.
- Встроенные и sidecar-индексы, построение и извлечение sidecar,
  отложенная загрузка предыдущего блока, следующий контекст и статистика.

| Интерфейс Go | Интерфейс C |
| --- | --- |
| `SearchTableConfig` | `minlz_search_config` |
| `WriterSearchTable`, `WriterSidecar` | Параметры потока и функции настройки writer |
| `BlockSearcher`, `SidecarSearcher` | `minlz_block_searcher`, `minlz_sidecar_searcher` |
| `SearchResult.PrevBlock()` | `minlz_search_result_load_previous` |
| `BuildSidecar`, `ExtractSidecar` | `minlz_build_sidecar`, `minlz_extract_sidecar` |
| `SearchStats`, `WindowStat` | `minlz_search_stats`, `minlz_search_window_stat` |

## Проверка

Укажите в `MINLZ_GO_REPO` репозиторий Go с API v1.2.0. CTest добавит
взаимные проверки блоков, потоков, поиска, sidecar, извлечения и статистики
для всех уровней сжатия, а также детерминированную случайную матрицу поиска.
Строгие проверки таблиц исключают незаметный переход к распаковке блоков
при несовместимой сжатой таблице. См. [тестирование](TESTING.ru.md).

Сжатые байты не обязаны совпадать с Go. Распакованные данные должны
совпадать полностью. Сравнение размера — отдельный критерий измерений
на указанных наборах, а не требование формата или гарантия для любых данных.

В теге Go v1.2.0 есть ошибка порядка повторного использования буфера
при поиске одного префикса в конечном хвосте. Соответствующий тест получает
поток или sidecar от Go и проверяет точное ожидаемое совпадение в C,
не опираясь на затронутый результат поиска Go. Для потоков C сохраняются
проверки распаковки средствами Go.

## Ограничения

Публичного API словарей нет. Резервная распаковка Snappy/S2 недоступна;
`MINLZ_WITH_FALLBACK` не подключает реализацию даже при значении `ON`.
`MINLZ_FULL_GO_PARITY=ON` приводит к ошибке конфигурации. Функции преобразования LZ4 возвращают `MINLZ_UNSUPPORTED`.
Режимы CLI HTTP, tail и follow не реализованы. Библиотека не зависит
во время выполнения от Go или внешних библиотек сжатия.
